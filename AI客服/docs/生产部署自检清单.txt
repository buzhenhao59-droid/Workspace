================================================================================
                   RUITALK 生产部署自检清单
                   版本: 2.0.0
                   生成日期: 2026-04-12
================================================================================

本清单用于 Ruitalk 系统部署到生产环境前的全面检查。
请逐项核对，每一项都必须通过才能上线。

================================================================================
一、环境变量安全检查（防SQL注入、防跨站攻击）
================================================================================

[ ] 1.1 SECRET_KEY
    - 要求: 128位随机字符串（运行: python -c "import secrets; print(secrets.token_hex(64))"）
    - 位置: .env 文件
    - 检查: 确保不是默认值，不是公开的密钥

[ ] 1.2 ADMIN_PASSWORD
    - 要求: 强密码（至少12位，包含大小写字母、数字、特殊字符）
    - 检查: 不要使用 123456789 等弱密码

[ ] 1.3 JWT_SECRET_KEY
    - 要求: 128位随机字符串
    - 检查: 与 SECRET_KEY 不同

[ ] 1.4 INTERNAL_API_SECRET / BUYER_CALLBACK_TOKEN
    - 要求: 64位随机十六进制字符串
    - 检查: 卖方和买方使用不同的密钥

[ ] 1.5 MYSQL_PASSWORD
    - 要求: 强密码（不要使用 root/123456 等默认密码）
    - 检查: MySQL 用户密码已修改

[ ] 1.6 REDIS_PASSWORD（如果启用Redis）
    - 要求: 设置Redis访问密码
    - 检查: REDIS_PASSWORD 已配置

[ ] 1.7 NEO4J_PASSWORD
    - 要求: Neo4j数据库密码已修改
    - 检查: 不是默认密码

[ ] 1.8 CORS配置
    - 要求: ALLOWED_ORIGINS 不能使用 *
    - 检查: 已配置为实际域名
    - 示例: https://seller.yourdomain.com,https://buyer.yourdomain.com

[ ] 1.9 ADMIN_PASSWORD_SALT
    - 要求: 64位随机字符串
    - 检查: 与其他密钥不同

================================================================================
二、静态资源压缩配置
================================================================================

[ ] 2.1 前端构建优化
    - 检查: npm run build 后前端资源已压缩
    - 验证: dist/ 目录中 CSS/JS 文件已压缩

[ ] 2.2 图片资源
    - 检查: 使用 WebP 格式或懒加载
    - 验证: 大图片已压缩

[ ] 2.3 字体资源
    - 检查: 使用 CDN 加速或本地压缩字体
    - 验证: 字体文件不超过 500KB

[ ] 2.4 Nginx/Gunicorn 配置
    - 检查: 已启用 Gzip 压缩
    - 验证: Response headers 包含 Content-Encoding: gzip

[ ] 2.5 静态文件缓存
    - 检查: 已配置静态资源缓存策略
    - 示例: CSS/JS 缓存 7 天，图片缓存 30 天

================================================================================
三、日志记录逻辑
================================================================================

[ ] 3.1 日志级别配置
    - 检查: 生产环境设置为 WARNING 或 ERROR
    - 配置: LOG_LEVEL=warning

[ ] 3.2 AI报错日志
    - 检查: DeepSeek API 调用失败已记录
    - 必记内容:
      * session_id
      * customer_id
      * error_type
      * error_message
      * timestamp
      * request_payload（脱敏后）

[ ] 3.3 人工分配失败日志
    - 检查: 转人工失败已记录
    - 必记内容:
      * session_id
      * customer_id
      * wait_time（等待时长）
      * failure_reason
      * notification_sent（是否发送通知）
      * timestamp

[ ] 3.4 日志轮转
    - 检查: 已配置日志文件轮转（避免磁盘满）
    - 配置: 使用 logging.handlers.RotatingFileHandler
    - 设置: maxBytes=104857600 (100MB), backupCount=10

[ ] 3.5 日志存储
    - 检查: 日志文件存储在 /var/log/ruitalk/ 或云存储
    - 检查: 日志文件权限 640

[ ] 3.6 敏感信息脱敏
    - 检查: 日志中不记录密码、Token、API Key
    - 检查: 手机号、身份证号等已脱敏（显示前3后4）

================================================================================
四、自动备份数据库任务计划
================================================================================

[ ] 4.1 MySQL 自动备份
    - 检查: 已配置每日自动备份
    - 命令: mysqldump -u root -p --single-transaction ruitalk > backup_$(date +%Y%m%d).sql
    - 建议: 每天凌晨 3:00 执行

[ ] 4.2 MySQL 备份保留策略
    - 检查: 保留最近 7 天每日备份
    - 检查: 保留最近 4 周每周备份
    - 检查: 保留最近 6 个月每月备份

[ ] 4.3 备份存储位置
    - 检查: 备份文件存储在独立存储（NAS/云存储）
    - 检查: 不在同一服务器磁盘（防止磁盘故障丢失）

[ ] 4.4 SQLite 自动备份（开发模式）
    - 检查: buyer.db 文件已配置备份
    - 命令: cp buyer.db buyer.db.backup.$(date +%Y%m%d)

[ ] 4.5 Redis 数据备份
    - 检查: 如果使用 Redis，已配置 RDB 持久化
    - 配置: save 900 1 / save 300 10（每15分钟或100次写操作）

[ ] 4.6 备份验证
    - 检查: 每月验证一次备份可恢复
    - 记录: 在文档中记录验证结果

[ ] 4.7 备份通知
    - 检查: 备份成功/失败发送邮件通知
    - 配置: BACKUP_NOTIFY_EMAIL=your@email.com
    - SMTP 配置: SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS

六、安全检查清单
================================================================================

[ ] 6.1 SQL注入防护
    - 检查: 所有用户输入使用参数化查询
    - 验证: 使用 ' OR 1=1 -- 测试输入框

[ ] 6.2 XSS防护
    - 检查: HTML输出已转义
    - 验证: <script>alert(1)</script> 不会执行

[ ] 6.3 CSRF防护
    - 检查: 重要操作需要CSRF Token
    - 验证: POST请求带Token

[ ] 6.4 速率限制
    - 检查: 已启用限流中间件
    - 验证: 超过限制返回429状态码

[ ] 6.5 会话安全
    - 检查: JWT Token 设置合理过期时间
    - 建议: ACCESS_TOKEN_EXPIRE_MINUTES=480 (8小时)

[ ] 6.6 HTTPS配置
    - 检查: 启用 HTTPS
    - 检查: HTTP 自动重定向到 HTTPS
    - 检查: SSL 证书未过期

[ ] 6.7 敏感文件保护
    - 检查: .env 文件不在公开目录
    - 检查: .gitignore 包含 .env
    - 检查: backup 文件不在 Web 根目录

八、部署后检查脚本
================================================================================

请在部署后运行以下检查命令：

# 1. 服务健康检查
curl -s http://localhost:8000/health | jq
curl -s http://localhost:8001/health | jq

# 2. Redis连接检查
redis-cli ping

# 3. MySQL连接检查
mysql -u root -p -e "SELECT 1"

# 4. 日志错误检查（最近1小时）
grep -i error /var/log/ruitalk/*.log | tail -50

# 5. 端口监听检查
netstat -tlnp | grep -E '8000|8001|6379|3306'

# 6. 进程状态检查
ps aux | grep -E 'uvicorn|python|celery' | grep -v grep
