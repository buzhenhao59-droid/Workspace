# Ruitalk 卖方智能客服系统 - 新手启动说明

感谢使用 Ruitalk 卖家客服系统！按照以下 3 步，3 分钟即可启动运行。

---

## 第 1 步：复制配置文件

在项目根目录下找到 `.env.example` 文件，**复制一份**并重命名为 **`.env`**：

```bash
# 方式一：在文件夹地址栏输入 cmd 回车，然后执行：
copy .env.example .env

# 方式二：直接右键 .env.example → 复制 → 重命名为 .env
```

> ⚠️ **重要**：`.env` 是配置文件，**不要把它发给别人**，里面包含密码等敏感信息。
>
> 💡 **不改任何内容也能用演示模式启动**（短信验证码会打印在 CMD 窗口中）。

---

## 第 2 步：安装依赖

```bash
# 在项目根目录打开 CMD 执行：
pip install -r "卖方终端/requirements.txt"
```

> 如果提示 `pip 不是内部或外部命令`，请先安装 Python（https://www.python.org/downloads/），安装时勾选 **"Add Python to PATH"**。
>
> 如果安装速度慢，可以加国内镜像：`pip install -r "卖方终端/requirements.txt" -i https://pypi.tuna.tsinghua.edu.cn/simple`

---

## 第 3 步：启动服务

**方法一（最推荐）— 双击 bat 文件**：

双击项目根目录下的 **`卖家系统启动.bat`** 即可自动启动所有服务。

**方法二 — 命令行一键启动**：

在项目根目录打开 CMD 执行：
```bash
python start_all.py
```

等待约 5 秒钟，看到提示 `所有服务已启动` 后，打开浏览器访问：

👉 **http://127.0.0.1:8000**

---

## 常见问题

**Q：浏览器显示「无法访问此网站」或 ERR_CONNECTION_REFUSED？**
A：等 5 秒后刷新页面。如果仍然不行，请检查 CMD 窗口是否还在运行（关掉窗口服务就停了）。

**Q：启动时提示「xxx 模块未找到」/ ModuleNotFoundError？**
A：请重新执行第 2 步安装依赖。

**Q：端口被占用报错？**
A：关掉其他占用 8000/8001 端口的程序，或重启电脑后再试。

**Q：系统会自动打开浏览器吗？**
A：双击 `.bat` 会自动打开。手动命令行启动时，请在浏览器手动输入 `http://127.0.0.1:8000`。
