# 2026-03-03 工作记录

## 拓岳科技跨境电商网站前端设计

### 需求概述
- 单页面应用（index.html）
- 左侧固定任务栏 + 上方标签栏 + z-index页面切换
- 右下角AI悬浮窗

### 五大模块结构

#### 1. 销售管理
- 订单中心：订单审核、拆分、合并、异常标记
- Listing管理：商品监控、调价、刊登、A+页面管理
- 售后中心：平台客服、退款退货、退货数据分析

#### 2. 产品与库存管理
- 产品库：SKU基础信息、图片品牌分类、1688货源配对
- 多仓库存：本地仓、FBA仓、海外仓
- 进出库流转：入库单、出库单、调拨单、盘点单、库存流水

#### 3. FBA仓储与补货
- 智能补货建议：销量/库存周转/投程时长数据 + 醒目补货方案
- 货件管理：发货计划、装箱任务、跟踪号管控

#### 4. 物流与供应链管理
- 物流渠道：物流商列表勾选、运费试算、面单打印、地图轨迹查询
- 采购管理：采购单创建、入库/质检/对账环节（红绿状态）

#### 5. 财务与报表管理
- 精细化利润核算：SKU利润报表
- 往来账款：供应商应付、平台收款、费用报销

#### 6. AI辅助工具（悬浮窗）
- 对话框形式，主动分析提示

### 交互细节
- 悬停菜单：进入立即显示，移出延迟1秒隐藏
- 页面加载：1秒动画
- 上方任务栏：可激活/关闭页面标签
- 核心内容占2/3，可下拉展开
