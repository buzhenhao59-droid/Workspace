# 拓岳科技跨境电商管理系统

## 项目结构

```
拓岳科技有限公司/
├── index.html          # 前端页面
├── api.js              # API服务封装
├── 启动后端.bat        # 一键启动后端
└── backend/            # 后端服务
    ├── server.js       # 服务主文件
    ├── package.json    # 依赖配置
    ├── README.md       # 后端说明
    └── data/           # 数据文件
        ├── users.js
        ├── orders.js
        ├── products.js
        └── ...
```

## 快速开始

### 方式一：双击启动
1. 双击 `启动后端.bat`
2. 等待服务启动（首次会自动安装依赖）
3. 浏览器打开 `index.html`

### 方式二：命令行启动
```bash
# 1. 启动后端
cd backend
npm install
npm start

# 2. 打开前端
# 用浏览器打开 index.html
```

## 访问地址

- **前端页面**: 直接打开 `index.html`
- **后端服务**: http://localhost:3000
- **API文档**: http://localhost:3000/api/docs

## 功能模块

### 1. 销售管理
- ✅ 订单中心（审核/拆分/合并/异常标记）
- ✅ Listing管理（调价/刊登/A+页面）
- ✅ 售后中心（退款退货/数据分析）

### 2. 产品与库存管理
- ✅ 产品库（SKU管理/货源配对）
- ✅ 多仓库存（本地仓/FBA仓/海外仓）
- ✅ 进出库流转（入库/出库/调拨/盘点）

### 3. FBA仓储与补货
- ✅ 智能补货建议（销量分析/库存周转）
- ✅ 货件管理（发货计划/装箱/跟踪）

### 4. 物流与供应链
- ✅ 物流渠道管理（运费试算/面单打印/轨迹查询）
- ✅ 采购管理（采购单/入库质检/供应商对账）

### 5. 财务与报表
- ✅ 精细化利润核算（SKU级别报表）
- ✅ 往来账款（应付/应收/报销）

### 6. AI辅助工具
- ✅ 商品描述生成
- ✅ 多语言翻译
- ✅ 差评智能分析

## 技术栈

### 前端
- HTML5 + CSS3 + JavaScript
- Font Awesome 图标库
- 响应式设计

### 后端
- Node.js + Express
- JWT 认证
- 文件存储（可升级数据库）

## 生产部署建议

1. **数据库**: 将文件存储改为 MySQL/PostgreSQL
2. **缓存**: 添加 Redis 提升性能
3. **安全**: 配置 HTTPS、密码加密
4. **日志**: 添加日志系统
5. **AI服务**: 对接真实的大模型API
6. **物流API**: 对接真实物流商接口
